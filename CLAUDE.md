# Smart Prediction Hub — notes for Claude / developers

Live prediction-market odds aggregator (Polymarket, Kalshi, Limitless, PredictIt) + blog/news + CMS.
Plain PHP 8.3, MariaDB, vanilla JS, Tailwind via CDN on the public pages. No framework, no build step
(except `deploy/build-layout.py` for the shared layout). Hosted on a CloudPanel VPS (nginx + PHP-FPM).

## Hard rules

- **The repo is public.** Never commit `app/config.php`, `.sql` dumps, passwords, API keys or server
  credentials. `app/config.sample.php` must only ever contain placeholders (`CHANGE_ME`).
- nginx ignores `.htaccess`. Private folders are blocked by `deploy/nginx-cloudpanel.conf` (`^~` locations).
  Every file in `app/`, `includes/`, `admin/includes/` must start with the `SPH_APP` guard.
- Admin pages: call `require_perm('…')` / `require_super()`; POST handlers use `require_post_csrf()`;
  escape output with `e()` (admin) or `sph_h()` (public). Use `q($sql, $params)` — always prepared statements.
- New permission → add it to `admin/includes/permissions.php`; it appears in the role editor automatically.
- DB changes go in `app/schema.php` (`CREATE TABLE IF NOT EXISTS` / `column_exists` checks), never by hand.
  Production runs them with `php app/cron/migrate.php` (called by `deploy/deploy.sh`).

## Layout of the code

| Area | Files |
| --- | --- |
| Live markets data | `app/markets/sources.php` (fetchers), `aggregate.php` (matching, cache), `store.php` (query), cron `app/cron/refresh-markets.php` → `app/cache/` |
| Market pages / API | `markets.php`, `event.php`, `api/markets.php`, `api/event.php`, `assets/markets.{js,css}` |
| Designed static pages | `index.html`, `reviews/*.html`, … — served through `page.php` (never directly) |
| Shared header/footer | defaults `includes/site-header.html`, `site-footer.html`; PHP pages use `includes/layout-top.php` / `layout-bottom.php` — all generated by `python3 deploy/build-layout.py .` from `index.html` |
| CMS core | `app/cms.php` (DB side, sanitiser, visual-editor engine `ve_*`, `cms_publish_cache()`), `app/site.php` + `app/render.php` (public side, reads `app/cache/cms/*` only — no DB) |
| Blog / news | `posts.php` (lists), `article.php` + `app/views/article.php`, `app/blog.php`, `assets/blog.css` |
| Admin | `admin/*.php`, shared UI in `admin/includes/` (`auth.php`, `layout.php`, `cms-ui.php`, `ve.php`), JS/CSS in `admin/assets/` (CSP is `script-src 'self'` — no inline scripts) |
| Site users | `user/` |

Every CMS save calls `cms_publish_cache()`, which rewrites `app/cache/cms/` (settings, page index, edited pages,
header/footer, redirects, market overrides). Public pages read those files, so they keep working if MySQL is down.

## URLs (see `deploy/nginx-cloudpanel.conf`)

`/markets`, `/markets/<cat>`, `/event/<id>`, `/blog`, `/blog/<slug>`, `/blog/category/<slug>`, `/news/…`,
`/sitemap.xml`. Everything else extension-less → `page.php` (redirects → hidden → CMS pages → static `.html`
→ 404). Old `.php`/`.html` URLs 301 to the clean ones. Admin and `user/` keep `.php` URLs.

## Run it locally

```bash
cp app/config.sample.php app/config.php   # point at a local MariaDB database
php app/cron/migrate.php                  # tables + default roles/categories
php app/cron/refresh-markets.php -v       # market data (needs internet)
php -S 127.0.0.1:8080 deploy/router.php   # same URL rules as nginx
```

Create the first admin at `/admin/setup.php` (needs `SETUP_KEY` from config), then delete that file on servers.

## Deploying

Work on a branch, open a PR into `main`. After merge, on the VPS as the site user:
`cd /home/smartpredictionhub/htdocs/smartpredictionhub.com && sudo -u smartpredictionhub bash deploy/deploy.sh`.
If `deploy/nginx-cloudpanel.conf` changed, paste it into CloudPanel → Site → Vhost again. More in `DEPLOY.md`.
